# Hand Recognition System for Gaming 🎮

## Overview
This project combines the power of **Python**, **OpenCV**, and **MediaPipe** to create a hand recognition system for gaming. By leveraging computer vision techniques, we've developed a system that detects hand gestures and maps them to keyboard inputs, allowing players to control the popular game "Hill Climb Racer" seamlessly without a physical controller.

## Features
- **Hand Tracking**: Utilizing MediaPipe's hand tracking module, we accurately locate and track hand movements.
- **Gesture Recognition**: We've programmed the system to recognize specific hand gestures, enabling intuitive control within the game.
- **Seamless Integration**: The system seamlessly integrates with the game, enhancing the overall gaming experience.
- **Hands-Free Gaming**: Say goodbye to physical controllers! Our project opens up new possibilities for hands-free gaming interfaces.

## Getting Started
1. Clone this repository to your local machine.
2. Install the necessary dependencies (Python, OpenCV, MediaPipe).
3. Run the `inference_classifier.py` file to start the hand recognition system.

## Usage
1. Launch "Hill Climb Racer."
2. Raise your hand and make gestures to control the game.
3. Enjoy a unique and interactive gaming experience!
